# Desenvolvimento de Produtos Próprios

## Objetivo
Criar produtos autorais a partir do ciclo NEXA Studio → Sótão 3D.

## Pipeline

```text
Ideia → conceito → arte/modelo → validação digital → protótipo → iteração → produção → acabamento/QC → catálogo → venda → feedback
```

## Gate de produto próprio
Um produto só avança para catálogo quando possuir:
- identificação e versão;
- origem/autoria documentada;
- licença verificada quando houver terceiros;
- protótipo físico aprovado;
- custo medido;
- fotografia;
- descrição comercial;
- registro de feedback após venda/teste.

## Coleção inicial
As linhas de decoração, geek/colecionáveis, funcionais e personalizados permanecem como famílias de exploração. A seleção de produtos campeões deve ser baseada em dados reais de produção e mercado.

## Indicadores
- projetos criados;
- protótipos aprovados;
- versões por produto;
- custo médio;
- tempo médio;
- vendas;
- recorrência;
- taxa de revisão.
