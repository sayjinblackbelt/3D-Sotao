# Inventário e Catálogo de Produtos

## Objetivo
Transformar o estoque físico existente em uma base comercial rastreável, sem inventar dados ainda não medidos.

## Cadastro mínimo

| Campo | Uso |
|---|---|
| Código | Identificação única: DEC-001, GEEK-001, FUNC-001, PERS-001 |
| Nome | Nome comercial |
| Linha | Decoração / Geek / Funcional / Personalizado |
| Status | Teste / Candidato / Catálogo / Personalizado / Sazonal / Descontinuado |
| Quantidade | Estoque físico atual |
| Material | PLA ou outro |
| Cor | Cor do filamento |
| Peso (g) | Medição real |
| Tempo (h) | Tempo real ou estimado do slicer |
| Acabamento | Cru / lixado / primer / pintado / verniz |
| Origem | Próprio / terceiro / licença |
| Versão | Versão do modelo |
| Foto | Caminho ou URL |
| Custo | Ficha financeira interna |
| Preço | Preço comercial |
| Observações | Informações adicionais |

## Regra
Nenhum produto entra como catálogo definitivo sem identificação, origem/licença, resultado físico e dados mínimos de custo.

## Processo
1. Separar fisicamente as peças.
2. Agrupar peças iguais.
3. Fotografar.
4. Atribuir código.
5. Registrar peso e demais dados disponíveis.
6. Classificar status.
7. Criar ficha de produto.
8. Selecionar candidatos ao catálogo.

## Dados ainda não preenchidos
O inventário real deve ser preenchido a partir da conferência física. Este documento não substitui a contagem real.
