# Log de Produção

## Objetivo
Registrar cada impressão relevante para medir capacidade, qualidade, consumo e retrabalho.

## Registro

| Campo | Registro |
|---|---|
| Data | AAAA-MM-DD |
| Impressora | Ender 3 V3 SE / A1 Mini / outra |
| Produto | Código |
| Versão | Modelo/arquivo |
| Filamento | Marca/cor/tipo |
| Peso (g) | Real |
| Tempo (h) | Slicer/real |
| Resultado | Aprovado / falha / retrabalho |
| Motivo da falha | Classificação |
| Acabamento | Processo |
| QC | Aprovado / revisão |
| Observação | Livre |

## Indicadores
- impressões por período;
- horas de máquina;
- gramas de filamento;
- taxa de falha;
- taxa de retrabalho;
- tempo médio por produto;
- consumo médio por produto.

## Regra
Registrar o resultado real. Estimativas podem existir, mas devem ser identificadas como estimativas.
