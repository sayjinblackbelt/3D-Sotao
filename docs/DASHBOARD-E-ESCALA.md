# Dashboard, Automação e Escala

## Camadas

### 1. Dados
Produtos, estoque, produção, vendas e custos.

### 2. Indicadores
Produção, comercial, financeiro e ecossistema NEXA.

### 3. Dashboard
Visão consolidada para acompanhamento periódico.

### 4. Automação
Formulários → planilhas → cálculos → indicadores → relatórios.

## Painéis

**Produção:** impressões, horas, filamento, falhas, retrabalho.

**Comercial:** contatos, orçamentos, vendas, conversão, ticket médio, recorrência.

**Financeiro:** faturamento, custos, resultado operacional, reinvestimento.

**Produtos:** estoque, giro, vendas, margem, falhas e tempo de máquina.

**NEXA:** projetos, protótipos, versões, produtos próprios e feedback.

## Regra de automação
Automatizar depois de estabilizar o processo manual. Automação não deve esconder dados faltantes nem criar números estimados como se fossem reais.

## Escala
A expansão do parque de máquinas deve ser precedida por análise de demanda, utilização, capacidade, custos, caixa e necessidade tecnológica.

## Critérios para novo equipamento
- demanda não atendida;
- utilização das máquinas atuais;
- redução esperada de gargalo;
- compatibilidade com materiais e produtos;
- custo total de propriedade;
- impacto no caixa;
- manutenção e espaço;
- retorno operacional esperado.

## Estado atual
As duas máquinas existentes permanecem como base de observação durante 2026. A decisão de expansão será baseada no histórico acumulado, não apenas em desejo de aquisição.
