# Roadmap Operacional — Ecossistema Sótão 3D + NEXA Studio

## Ordem oficial

1. Validar GitHub Pages.
2. Inventariar peças e materiais reais.
3. Codificar e classificar produtos.
4. Fotografar e organizar mídia.
5. Medir custo e definir preço.
6. Registrar produção.
7. Controlar estoque.
8. Estruturar operação comercial.
9. Publicar vitrine digital.
10. Integrar NEXA Studio → Sótão 3D.
11. Desenvolver produtos próprios.
12. Consolidar dashboard.
13. Automatizar rotinas estáveis.
14. Medir demanda, capacidade e utilização.
15. Avaliar expansão de máquinas.
16. Escalar somente com evidência operacional e financeira.

## Método de execução

Para cada etapa:

**Executar → testar → corrigir → validar → registrar → avançar.**

## Critério de conclusão
Uma etapa é considerada concluída somente quando houver evidência registrada. Dados físicos, custos, vendas e estoque não devem ser inventados para preencher lacunas.

## Estado inicial desta versão

- documentação-base: concluída;
- fluxo NEXA → Sótão: documentado;
- linhas de produtos: documentadas;
- fluxo operacional: documentado;
- padrões de inventário, custos, produção, estoque, comercial, produtos próprios e dashboard: criados;
- site institucional/vitrine: estruturado;
- GitHub Pages: aguardando validação externa de publicação;
- inventário real: aguardando conferência física;
- custos reais por produto: aguardando medição;
- vendas e indicadores históricos detalhados: aguardando consolidação.

## Regra de automação
A automação deve acelerar um processo já compreendido. Não deve substituir a coleta de dados reais nem transformar hipóteses em fatos.
